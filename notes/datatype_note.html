파이썬 데이터 타입 노트

코드에 나오는 파이썬 데이터 타입·문법 기초를 한곳에. 워크스루에서 타입이 헷갈리면 여기로. (수학 개념은 수학·통계 용어 노트 참조)

파이썬 데이터 타입 (Python data types) — 클릭해서 펼치기
① 스칼라 scalar — 값 하나
int 정수 integer
소수점 없는 수
예: n_genes = 60
float 소수
소수점 있는 수
예: expr = 2.73
str 문자열 string
글자/텍스트
예: name = 'GeneA'
bool 참/거짓 boolean
True 또는 False
예: is_train = True
② 컨테이너 container — 여러 값 묶음
list 목록
순서 있음, 수정 가능, 아무거나 담음. 수학 연산 안 됨
예: [3, 1, 4]
tuple 묶음(고정)
순서 있지만 수정 불가. shape가 tuple
예: (400, 60)
dict 사전 dictionary
키(key)→값(value)으로 찾음
예: data['ctrl']
set 집합
중복 없음, 순서 없음
예: {1, 2, 3}
③ numpy — 숫자 계산 전용
ndarray = array numpy 배열
ndarray와 array는 같은 말. list와 달리 숫자 전용, 원소별 계산 됨, 다차원 OK.
예: np.array([3,1,4])
ndarray (1D) 벡터 vector
숫자 한 줄
예: shape (60,)
ndarray (2D) 행렬 matrix
행×열 격자
예: shape (400, 60)
인덱싱 [ ] 대괄호로 값 꺼내기 (indexing)
대괄호는 "안에서 꺼낸다"는 공통 의미. dict면 키로, ndarray면 행/원소 선택. 함수 호출(())이 아님.
d['ctrl']=키로 / arr[3]=3번 행 / arr[[3,4,5]]=여러 행 / arr[:3]=앞3행 / arr[:,0]=모든행 0열
. 과 ( ) 점=안으로 들어가기, 괄호=함수 실행
점 . = 안으로 들어가기 (np.random = np 안의 random). 괄호 () = 함수 실행 (default_rng(seed)는 실행, default_rng만 쓰면 함수 자체).
np=라이브러리 / np.random=하위모듈 / np.random.default_rng=함수 / rng=변수(Generator 객체 담김)
화면 출력 (repr) 변수를 치면 실제로 이렇게 보여 → 타입 구분법
파이썬에서 변수 이름만 치면 아래처럼 나온다. 괄호 모양으로 타입을 안다.
화면에 이렇게 나오면모양타입

array([...])대괄호 1겹#1565c0
[3, 4, 5, ...]array 없이 대괄호#5f6368
{'k': v, ...}중괄호, key:value#7b1fa2
(400, 60)소괄호#2e7d32
